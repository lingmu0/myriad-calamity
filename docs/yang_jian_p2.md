# 杨戬 · P2 兵器变化·雷神

Minecraft 1.21.1 / NeoForge 21.1.233；P2 于 0.8.0 加入，0.9.0 接续 P3。

本版接续 [P1](yang_jian_p1.md)，加入制作规格中的第二阶段。使用登云符进入原来的云海神台，无需重新生成平台。

## 连续挑战

`/give @s myriad_calamity:cloud_talisman`

在非和平难度的安全地面右键登云符，四秒准备后开始 P1。生命降至最大值 75% 时清除当前攻击和召唤物，执行 7.2 秒巨型雷斧转阶段。杨戬在过渡期间免伤，玩家需要跳跃躲避；结束后刷新第二条防御，持雷斧进入 P2。生命值保留，阶段保护防止单次高额伤害跳过阶段。

| 转阶段时间 | 动作与伤害 |
| --- | --- |
| 0～1.2 秒 | 飞向平台中心上空，升高 8 格。 |
| 1.2～2 秒 | 雷斧出现并增长至常规雷斧的 3 倍。 |
| 2～3.2 秒 | 空中挥舞半圈，地面预警覆盖半径 22 格的整个战斗平台。 |
| 3.2～3.6 秒 | 快速下砸；3.6 秒时全场贴地冲击，默认 14 点伤害，起跳可躲。 |
| 4.8～6.3 秒 | 地震波从中心向外扩散至场边，默认 10 点伤害，再次起跳躲避。 |
| 6.3～7.2 秒 | 收势，巨斧缩回常规大小；接着进入 P2 技能选择。 |

两次伤害各自对同一玩家最多判定一次，只覆盖地面以上 0.45 格的高度，按 `damage` 配置缩放。扩散波扫过后不留伤害区域；不破坏平台。读档时未完成的雷斧过渡从完整预警重新开始，保留地面中心，避免在半空复现未预警的伤害。

P2 生命降至最大值 50% 后播放 3.5 秒天眼开启动画，再进入 [P3](yang_jian_p3.md)。已在 0.7.0 / 0.8.0 完成的旧版挑战保留结束状态，重新进入才能体验完整三阶段；原有首通奖励记录继续保留。

P2 受到伤害时也先扣当前防御条，防御条有值时不会损失生命；防御条耗尽后会进入两分钟暴露期，期间伤害直接扣生命，防御条不会单独触发天眼转阶段。生命达到 50% 阈值才进入天眼转阶段。防御条存在时，待机远距格挡和连续近战压力格挡均可触发。

## 第二阶段技能

| 技能 | 表现与应对 |
| --- | --- |
| 雷斧召唤 | 召出更大的雷斧，进入斧系动作；同时获得 3 层「雷斧残响」，接下来的 3 次实际攻击会在攻击路线或落点留下 48 tick 的雷电残留，每次接触额外造成按 `damage` 缩放的 4 点闪电伤害，并伴随电弧特效。召唤后的下一招强制保持雷斧，不会立即切回其他武器。 |
| 雷斧重砸 | 举斧、跃起、落地雷爆；有明确的圆形落点预警，移出圆圈躲避。 |
| 雷斧连击 | 横斩、横斩、上挑、重砸，末段扩大范围并伴随雷电。 |
| 旋转飞剑 | 五把飞剑在召唤瞬间同时显形并环绕；第一把完成“预警→射出”后，下一把才开始预警并射出，五把依次处理。每把飞行前段有限追踪，预警之后横移可躲避；飞剑实体独立运行，不阻塞杨戬继续使用其他技能。 |
| 拔剑斩 | 收刀蓄势后快速拔剑，短时间斩过前方区域。 |
| 雷鞭横扫 | 更远的前方扇形扫击，依照地面预警移出范围。 |
| 雷鞭回旋 | 覆盖全高度的一周横扫，按右向左的链节方向旋转；可跳起或离开圆形范围躲避。 |
| 雷电突刺 | 沿预警直线突进，实际走过的路线留下短时雷电；路线伤害有间隔，可跳起躲避。 |
| 隐身突进 | 短暂消隐并重新出现，出现位置与突进方向有提示，再释放高速攻击。 |
| 快慢刀 | 快、快、明显停顿、重击，注意重击前的停顿。 |

技能选择结合距离、玩家使用物品、连续攻击压力、当前兵器、剩余防御与冷却；组合有长度上限，完成后固定恢复，不能无限追击。各阶段技能池独立，天眼和万剑诀只在 P3 使用。

三个阶段的垫步从第 0 tick 立即移动，并同步从副手直接投出一枚飞刀，不显示锁定线或地面预警；沿起步时锁定方向直线飞行，默认 7 点伤害。当前兵器继续留在主手，前移不中断。出手前被打断会取消飞刀，已经飞出的刀继续飞行，命中或到期后移除。

飞剑和地面雷电使用专门的实体和渲染，不会破坏平台或点燃场地。五把飞剑实体在召唤瞬间全部生成并保持在环阵中可见；预警仍按单把队列发布，当前剑射出后才为下一把生成锁定线。飞剑实体独立运行，不会阻塞杨戬的主技能状态。雷斧残响使用真实闪电伤害来源，并渲染蓝白电弧与电火花。全部危险预警由服务器发布，显示当前已锁定的范围。

可编辑模型与动画工程为 [`modeling/yang_jian_p2.bbmodel`](../modeling/yang_jian_p2.bbmodel)。保留原人物几何，新增三种兵器共 411 个方块；全工程包含 31 套动画。雷斧腾空、落地重击、拔剑和雷鞭动作已在 Blockbench 中检查。

## 配置与验证

`config/myriad_calamity-common.toml` 的 `[yangJian]` 中新增：

```toml
phase2Guard = 220.0
phase3Guard = 260.0
```

`guard` 控制第一阶段防御，`phase2Guard` 控制第二阶段防御，`phase3Guard` 控制第三阶段防御；`health` 控制整场最大生命；`damage` 同时缩放三个阶段的技能伤害。P3 入场生命保底详见 P3 文档。旧配置缺失的新字段由 NeoForge 补全。

不启动游戏的检查命令：

```powershell
.\gradlew.bat build --console=plain
python tools/validate_yang_jian_assets.py
python tools/check_yang_jian_transition_contact.py
python tools/validate_assets.py
```

构建检查包括技能时序、阶段技能池、冷却与组合限制、扫掠命中、飞剑转向限制和雷电伤害间隔；资源检查覆盖动画、兵器、贴图与最终 JAR。

0.9.3 本轮验证：Gradle 构建成功，4707 项逻辑检查通过，其中 1820 项覆盖雷斧转阶段和跳跃躲避；模型/动画校验通过，巨斧完整几何的 481 个姿势均无穿地，最终 JAR 的 10681 项资源与打包检查通过。本轮未启动 Minecraft 实测。

仍需游戏内验收：P1 → P2 的实际切换、兵器与命中的观感、圆形/扇形预警对应范围、跳跃躲雷鞭和雷电路线、隐身出现的反应时间，以及多人服务器上的同步。此轮采用编译和非游戏检查，未启动 Minecraft。
