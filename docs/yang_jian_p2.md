# 杨戬 · P2 兵器变化·雷神

Minecraft 1.21.1 / NeoForge 21.1.233；P2 于 0.8.0 加入，0.9.0 接续 P3。

本版接续 [P1](yang_jian_p1.md)，加入制作规格中的第二阶段。使用登云符进入原来的云海神台，无需重新生成平台。

## 连续挑战

`/give @s myriad_calamity:cloud_talisman`

在非和平难度的安全地面右键登云符，四秒准备后开始 P1。生命降至最大值 75% 时清除当前攻击和召唤物，执行 7.2 秒巨型雷斧转阶段。杨戬在过渡期间免伤，玩家需要跳跃躲避；结束后刷新第二条防御，持雷斧进入 P2。生命值保留，阶段保护防止单次高额伤害跳过阶段。

| 转阶段时间 | 动作与伤害 |
| --- | --- |
| 0～1.2 秒 | 飞向平台中心上空，升高 8 格。 |
| 1.2～2 秒 | 雷斧出现并增长至常规雷斧的 3 倍；杨戬双手接住斧柄，左手握在右手上方。 |
| 2～3.2 秒 | 空中沿同一方向转满一整圈（360°），双手握柄带着巨斧转，地面预警覆盖半径 22 格的整个战斗平台。 |
| 3.2～3.6 秒 | 快速下砸；下砸瞬间左手松开斧柄，回到原来的单手砸击动作。3.6 秒时全场贴地冲击，默认 14 点伤害，起跳可躲。 |
| 4.2～4.8 秒 | 第一道地震波（84～95 tick）从中心向外扩散至场边，默认 10 点伤害，起跳躲避。 |
| 4.8～6.3 秒 | 第二道地震波（96～126 tick）紧随其后，同样扩散至场边，默认 10 点伤害，再次起跳躲避。 |
| 6.3～7.2 秒 | 收势，巨斧缩回常规大小；接着进入 P2 技能选择。 |

转阶段的巨斧是**双手持握**：双手间距恒定在 0.62～0.65 格，左手掌心始终贴在斧柄轴线上（最大偏差 0.10 格）并对齐握持轴，从 32 tick 握到 68 tick，72 tick 落砸时松开。双手姿态由 `tools/generate_yang_jian_p2_animations.py` 中的 `TWO_HANDED_GRIP` 表按关键帧给出，`tools/check_yang_jian_transition_grip.py` 逐 1/4 tick 复核（145 个姿态）。伺服端的升空、伤害与冲击波时间轴完全未改。

下砸与两道地震波各自对同一玩家最多判定一次，只覆盖地面以上 0.45 格的高度，按 `damage` 配置缩放。两道波之间留有 1 tick 的落地间隙，普通跳跃（12 tick 滞空）可以依次躲开三道判定；每道波都从中心重新起算，不会把上一道的波缘当成向内扫过的伤害。扩散波扫过后不留伤害区域；不破坏平台。读档时未完成的雷斧过渡从完整预警重新开始，保留地面中心，避免在半空复现未预警的伤害。

P2 生命降至最大值 50% 后播放 3.5 秒天眼开启动画，再进入 [P3](yang_jian_p3.md)。已在 0.7.0 / 0.8.0 完成的旧版挑战保留结束状态，重新进入才能体验完整三阶段；原有首通奖励记录继续保留。

P2 受到伤害时也先扣当前防御条，防御条有值时不会损失生命；防御条耗尽后会进入两分钟暴露期，期间伤害直接扣生命，防御条不会单独触发天眼转阶段。生命达到 50% 阈值才进入天眼转阶段。防御条存在时，待机远距格挡和连续近战压力格挡均可触发。

## 第二阶段技能

| 技能 | 表现与应对 |
| --- | --- |
| 雷斧召唤 | 召出更大的雷斧，进入斧系动作；同时获得 3 层「雷斧残响」，接下来的 3 次实际攻击会在攻击路线或落点留下 48 tick 的雷电残留，每次接触额外造成按 `damage` 缩放的 4 点闪电伤害，并伴随电弧特效。召唤后的下一招强制保持雷斧，不会立即切回其他武器。 |
| 雷斧重砸 | 举斧、跃起、落地雷爆；有明确的圆形落点预警，移出圆圈躲避。 |
| 雷斧连击 | 横斩、横斩、上挑、重砸，末段扩大范围并伴随雷电。 |
| 旋转飞剑 | 五把飞剑在召唤瞬间同时显形并环绕，按原有间隔依次瞄准和射出，不显示预警线或落点圈。环绕结束后剑尖持续指向玩家（仍在阵中等候的剑也一样），射出时才按玩家当前位置锁定方向；每把飞行前段有限追踪，仍可横移躲避。飞剑实体独立运行，不阻塞杨戬继续使用其他技能。 |
| 拔剑斩 | 收刀蓄势后快速拔剑，短时间斩过前方区域。 |
| 雷鞭横扫 | 更远的前方扇形扫击，链节**顺时针**扫过，依照地面预警移出范围。 |
| 雷鞭回旋 | 覆盖全高度的一周横扫，链节与命中都**顺时针**转；可跳起或离开圆形范围躲避。 |
| 雷电突刺 | 沿预警直线突进，突进结束后整条走过的路线被铺成蓝色雷电场；路线伤害有间隔，可跳起躲避。 |
| 隐身突进 | 短暂消隐并重新出现，出现位置与突进方向有提示，再释放高速攻击。 |
| 快慢刀 | 快、快、明显停顿、重击，注意重击前的停顿。 |

技能选择结合距离、玩家使用物品、连续攻击压力、当前兵器、剩余防御与冷却；组合有长度上限，完成后固定恢复，不能无限追击。各阶段技能池独立，天眼和万剑诀只在 P3 使用。

三个阶段的垫步从第 0 tick 立即移动，并同步从副手直接投出一枚飞刀，不显示锁定线或地面预警；沿起步时锁定方向直线飞行，默认 7 点伤害。当前兵器继续留在主手，前移不中断。出手前被打断会取消飞刀，已经飞出的刀继续飞行，命中或到期后移除。

飞剑和地面雷电使用专门的实体和渲染，不会破坏平台或点燃场地。五把飞剑实体在召唤瞬间全部生成并保持在环阵中可见；预警仍按单把队列发布，当前剑射出后才为下一把生成锁定线。飞剑实体独立运行，不会阻塞杨戬的主技能状态。雷斧残响使用真实闪电伤害来源，并渲染蓝白电弧与电火花。全部危险预警由服务器发布，显示当前已锁定的范围。

### 雷痕（雷斧残响）

雷斧召唤会授予 **3 层「雷斧残响」**；接下来的招式每消耗一层，就在地面铺出一片**蓝色雷电场**，覆盖招式**实际打出的整个范围**（与预警读取同一套几何，不再是单条直线）：

| 触发招式 | 雷痕范围 |
| --- | --- |
| 雷斧重砸 | 以落点为中心、半径 6.4 格的圆 |
| 雷斧连击 / 快慢刀（每段） | 该段的扇形（半径与开角随段落变化，末段为整圆） |
| 拔剑斩 | 半径 7 格、160° 扇形 |
| 雷鞭横扫 / 回旋 | 半径 11 格 200° 扇形 / 半径 10.5 格整圆 |
| 隐身突进 | 突进路线整条车道（半宽 1.2 格） |
| 射出飞剑 | 该剑从环阵射向玩家的整条路线（半宽 1.2 格） |
| 雷电突刺 | 本次实际走过的整条车道，不消耗额外层数 |

表现上接近 P3 的红雷天罚，只是蓝色：呼吸的地面覆盖、龟裂抖动的地面边缘、按范围铺开的多根 **14 格全高蓝色雷柱**，以及贴着地面爬动的电弧。站在范围内、且脚踩在被覆盖的地面上时，每 12 tick 受到一次默认 4 点（按 `damage` 缩放）的闪电伤害；跳起即可躲开，玩家自建的墙体也能挡住放电。

雷痕**不会自行消失**，会一直留到下一次「雷斧召唤」（届时旧雷场被清空并重新获得 3 层）；阶段切换、破防收招与挑战结束时一并清除。同一时刻最多只会有 3 层招式雷痕加一条雷电突刺车道，因此场地不会被无限堆满。

可编辑模型与动画工程为 [`modeling/yang_jian_p2.bbmodel`](../modeling/yang_jian_p2.bbmodel)。保留原人物几何，新增三种兵器共 411 个方块；全工程包含 31 套动画。雷斧腾空、落地重击、拔剑和雷鞭动作已在 Blockbench 中检查。

## 配置与验证

`config/myriad_calamity-common.toml` 的 `[yangJian]` 中新增：

```toml
phase2Guard = 220.0
phase3Guard = 260.0
showAttackIndicators = false
```

`guard` 控制第一阶段防御，`phase2Guard` 控制第二阶段防御，`phase3Guard` 控制第三阶段防御；`health` 控制整场最大生命；`damage` 同时缩放三个阶段的技能伤害。P3 入场生命保底详见 P3 文档。旧配置缺失的新字段由 NeoForge 补全。

`showAttackIndicators` 默认 `false`：除二阶段转阶段下砸保留整场范围预警外，杨戬不再绘制任何地面攻击范围提示；三阶段剑雨与红雷改用贴合兵器的落地痕迹（剑痕 / 雷痕）表示落点范围。改为 `true` 可恢复原来的路线、扇形与落点圆圈预警。

不启动游戏的检查命令：

```powershell
.\gradlew.bat build --console=plain
python tools/validate_yang_jian_assets.py
python tools/check_yang_jian_transition_contact.py
python tools/check_yang_jian_transition_grip.py
python tools/validate_assets.py
```

构建检查包括技能时序、阶段技能池、冷却与组合限制、扫掠命中、飞剑转向限制和雷电伤害间隔；资源检查覆盖动画、兵器、贴图与最终 JAR。
