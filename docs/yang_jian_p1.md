# 杨戬 · P1 云海神台试炼

Minecraft 1.21.1 / NeoForge 21.1.233 及同系列兼容版本。

第一阶段「三尖两刃刀·神将」包含生命值、防御条、按距离和战况加权的技能选择，以及 P1 的全部十项技能/机制。生命降至最大值 75% 时执行巨型雷斧转阶段攻击，再刷新防御进入 [P2「兵器变化·雷神」](yang_jian_p2.md)。第二阶段生命降至 50% 后开眼进入 [P3「天眼全开·神威」](yang_jian_p3.md)，最终阶段生命耗尽才完成挑战。

## 进入与返回

1. 合成「登云符」，或从万象灾厄创造物品栏取出。测试指令：`/give @s myriad_calamity:cloud_talisman`。
2. 在非和平难度的安全地面上右键，进入独立的云海维度。生存模式下进行战斗；创造和旁观玩家不会成为攻击目标。
3. 四秒准备后，杨戬在平台北侧现身。场地战斗半径为 22 格，外围有浅蓝结界护栏、云层和远雾。
4. 连续完成 P1、P2、P3 后，再次右键登云符，或右键平台南侧磁石「归途石」，返回进入前的位置。

登云符不消耗，配方如下；空白处不放物品：

| | 羽毛 | |
| 金锭 | 纸 | 金锭 |
| | 末影珍珠 | |

平台目前每次接受一名挑战者，其他玩家会收到占用提示。战斗期间锁定离场；跌出边缘会被送回场内。挑战落败时保留随身物品并返回，离线或退出导致的中断会在重新进入时处理返程。原地点被堵住时会寻找附近安全位置，找不到则使用主世界安全出生位置，不改动原世界方块。

每位玩家在每个存档首次通过当前试炼获得一个「神将印记」。已在旧版 P1 领取的记录继续保留。背包满时保存待领取状态，腾出空位后自动领取。奖励不会落入虚空。

## P1 战斗

| 技能/机制 | 行为与应对 |
| --- | --- |
| 普通连击 | 横斩、上挑、回旋斩、下劈，近距离优先，重击前有更长蓄力。回旋斩为**顺时针**整圈。全程不会变招。 |
| 四连斩 | 较快的四段近战，末段带圆形落点预警和击退；回旋段为**顺时针**整圈。目标在后续段开始前跑出 5.5 格，剩余段会变招。 |
| 六连斩 | 快、快、慢、快、快、重击；保持同一连招目标，末段范围更大；两段回旋都是**顺时针**整圈。目标跑出 5.5 格时剩余段会变招。 |
| 掷刀 | 后撤掷刀，初始方向遵循预警，飞行前半秒有有限转向，随后突进追击。 |
| 垫步飞刀 | 垫步从第 0 tick 立即开始，副手飞刀同步直接投出，不显示锁定线或地面预警；沿起步时锁定方向直线飞行，横移可躲。 |
| 突刺 | 蓄力锁定直线路径，六 tick 穿越整段路线；蓄力后横向移开。 |
| 哮天犬召唤 | 召出可击败的独立战斗伙伴，存活时不会重复召唤。 |
| 哮天犬协同 | 哮天犬侧移扑击，与杨戬的横斩、后续突刺构成组合。 |
| 哮天印记 | 哮天犬命中施加四秒标记，提高后续突刺的选择优先级和蓄力时的移动预判。 |
| 格挡 | 待机窗口受到正面近战攻击时可能格挡，连续攻击会增加格挡倾向。 |
| 格挡反击 | 成功格挡后可能经过短暂停顿与预警发起快速突刺。 |

除垫步飞刀外，红橙色地面扇形、圆圈和长条是实际攻击预警，均读取服务器已发布的当段攻击计划；这些预警受 `showAttackIndicators` 控制（默认关闭），关闭时 P1/P2 不再绘制地面范围提示。连招结束留有后摇；武器飞出时手中武器隐藏，飞刀沿飞行方向显示。模型沿用已经确认的精细方块造型，动画包含腰、胸、肩、肘、腕、膝、裙甲及发束联动；垫步动画加大了前后腿的跨步幅度，并让髋、腰、胸整体前倾压入动作。**大臂基础外展 10°**（`tools/build_yang_jian_v2.js` 的 `ARM_ABDUCTION`）：模型源、导出网格与三个 Blockbench 工程同步，避免手臂贴着胸甲导致小臂弯曲时穿插。

**长连招变招**：四连斩与六连斩只在目标仍在近战范围内（5.5 格）时继续下一段。若目标在后续段开始前跑开，剩余段会变招为**突刺**（中距离，直接突进追近）或**掷枪**（12 格以上，后撤投出长枪），并在变招时照常结算原连招的冷却，不会被反复刷出。普通连击（三段）始终把动作打完。

**旋转方向**：所有会转的技能统一**顺时针**——三段连招里各自回旋斩、雷鞭横扫与回旋、神威横扫与旋转、横向扫射激光的扫射方向，以及 P1→P2 转场的整圈旋转。动画里的旋转按镜像模型写成**递增偏航**代表顺时针；激光扫射在世界空间里按 `SWEEP_DIRECTION`（当前 `+1`）推进，取反即可让激光反向。

## 配置

首次运行自动生成 `config/myriad_calamity-common.toml`；机枢舞者的共享生命与伤害位于 `[cogworkDancer]` 区段（`health`／`damage`，默认 480／9），杨戬独立使用以下区段，不改变机枢舞者数值：

```toml
[yangJian]
health = 640.0
damage = 9.0
guard = 180.0
phase2Guard = 220.0
phase3Guard = 260.0
phase3HealthFloor = 0.4
showAttackIndicators = false
houndHealth = 40.0
houndDamage = 5.0
```

生命与防御上限对新挑战生效。各招式按基础伤害保持各自倍率。防御条单次削减存在上限，避免巨额单击跳过本阶段。

杨戬受到伤害时先扣当前阶段的防御条，防御条有值时不会损失生命；防御条耗尽后才会损失生命，空条持续 2400 tick（两分钟）后重新回满。生命达到 75%/50% 阈值才会切换阶段，防御条耗尽本身不会触发转阶段。防御条存在时，待机远距攻击和连续近战压力才会触发格挡。

## 资源与验证

```powershell
python tools/export_yang_jian_assets.py
python tools/generate_yang_jian_animations.py
python tools/generate_yang_jian_items.py
.\gradlew.bat build --console=plain
python tools/validate_yang_jian_assets.py
python tools/validate_assets.py
```

`build` 包含战斗时间轴/权重/扫掠判定测试，以及云台返回票据、奖励与异常存档的序列化测试。它们不启动 Minecraft。资源校验检查模型来源、骨骼与 UV、动画关键帧、语言、维度资源和最终 JAR。

仍需要游戏内验收：平台首次生成及重登、低模拟距离战斗、近战动画与实际命中观感、盾牌/不同护甲数值、击败哮天犬后的重召唤、失利及成功返程、多玩家占用提示。本轮没有启动游戏实测。

完整的后续阶段设计见 [制作规格文档](yang_jian_spec.md)。
