# 杨戬 · P3 天眼全开·神威

Minecraft 1.21.1 / NeoForge 21.1.233，模组版本 0.9.3。

使用登云符进入原云海神台，连续进行 P1 → P2 → P3。生命降至最大值 50% 后取消攻击、清除召唤物，播放 70 tick（3.5 秒）的天眼开启动画，期间免伤。随后换成紫色最终阶段血条，天眼发光，身体周围出现能量效果。

P3 的防御条默认 260 点。杨戬受到伤害时先扣防御条，防御条仍有值就不会损失生命；防御条归零后才会造成生命伤害，归零后的 2400 tick（两分钟）暴露时间结束时重新回满。防御条存在时才会触发远距格挡或连续近战压力格挡，空条期间投射物和近战伤害都直接作用于生命。开眼时保留现有生命；若低于配置的生命保底则补至保底，默认最大生命的 40%（默认最大生命 640，保底 256）。P3 单次生命伤害仍限制为最大生命的 15%，防止巨额伤害跳过战斗。最终死亡播放跪地收势，立即撤销所有危险效果，开放返程和首通奖励。

## 技能与预警

| 技能 | 流程与躲避方式 |
| --- | --- |
| 天眼开启 | 抬手聚气、开眼、展开手臂；只在 P2 破防时触发。 |
| 天眼激光 | 固定瞄准线预警 0.8 秒，再持续照射 1.6 秒；预警后横移。 |
| 横向扫射激光 | 起手准备 24 tick（不显示预警线）；本体与半透明、不可受击的视觉分身交替各扫 3 次。每次扫射 32 tick，半程 16 tick 切换；本体每次切换都会传送到新位置，分身在本体附近生成并在下一轮换位。 |
| 追踪激光 | 黄线预警 1.1 秒，随后照射 2.5 秒；三维转向限制为每 tick 0.7°，可通过横向持续移动甩开。 |
| 万剑诀 | 升空并分三波召剑，依次压制当前位置、移动预判位置、附近偏移区域。每波最多 8 剑，落点先显示 1.3 秒圆形预警。 |
| 剑雨 | 四波落剑，每波最多 8 个落点；每个落点提前 1.2 秒预警。剑尖朝下，实际落地后造成范围伤害。 |
| 红雷天罚 | 连续四轮、每轮三个红色落点；提前 1 秒预警，随后雷击爆发。落点会留下持续雷区，在范围内按伤害间隔反复造成伤害，直到下一次红雷天罚开始时清除上一轮雷区。 |
| 神威横扫 | 三尖两刃刀蓄力 1.3 秒，释放半径 12 格、170° 扇形刀气；近距离也可能改为半径 10 格的一周横扫。地面显示本次完整范围。 |
| 空中连招 | 升空 → 飞剑 → 追踪激光 → 锁定俯冲与刀击 → 红雷 → 收势。落剑、激光、俯冲和雷击分别提前预警。 |
| 神威天裁 | `DIVINE_JUDGEMENT`：升空聚气 → 万剑 → 俯冲刀击 → 两段激光 → 红雷 → 剑雨 → 落地。起手明显提示，冷却 60 秒；各段之间留出移动窗口。 |

最终阶段各招都保留短收招时间，普通技能结束后停顿 28 tick；技能按距离、玩家使用物品、剩余生命和冷却加权选择，避免原地重复同一招。开眼后最初 9 秒不抽取终极技能。

三个阶段均用快速垫步替代普通走路追近。每段 10 tick：第 0 tick 起立即前移，中间持续至第 8 tick，末尾 2 tick 收步，最多前移 6 格。P1/P2 接近到约 3.2 格，P3 保留约 8.5 格远程作战距离。起步与移动途中检查地面，障碍会阻挡移动；玩家迎面靠近时提前收步。从 0.9.3 起，垫步第 0 tick 同步从副手直接投出一枚无预警直线飞刀，默认 7 点伤害，可横移躲避。前移本身没有接触伤害，飞刀独立判定命中。攻击状态使用独立的生物锁定 UUID；外部系统把仇恨切换为其他存活生物后，杨戬会继续用该生物作为当前阶段目标，近战、飞刀、飞剑、激光和落点伤害都能命中它。

所有天眼激光和瞄准线统一为金黄色，白金色内芯外围带三股平滑闪动的电弧；电弧随扫射、追踪和障碍截断同步，保持在实际光束范围内。P3 每个技能 tick 都让杨戬身体朝向当前锁定玩家，因此升空、俯冲前摇、飞剑释放、追踪激光和天裁的空中分段不会出现身体朝向滞后。

杨戬处于待机或格挡姿态时，来自四格以外的实体攻击会自动格挡。远处投射物沿原速度反向弹回，并将其发射者改为杨戬；若伤害来源的 `actual` 与 `direct` 是同一个生物，则该生物受到 20 tick（1 秒）的强制停滞。普通正面格挡也会触发同样的眩晕和击退。杨戬自有的三尖两刃刀、飞剑及机枢剑光保留原控制者，避免反弹时破坏技能生命周期。

万剑和剑雨先生成分离的落点布局，再发布预警，避免场边裁剪把多个圆圈压到同一个位置。移动预测最多提前 4.5 格。单个 Boss 同时存在的 P3 危险实体上限为 48；同一玩家受到这些危险实体攻击时共用 12 tick 的伤害间隔，不因剑雨重叠而瞬间叠加多次伤害。

预警使用实际几何线与圆圈。预警和命中读取同一个服务器计划：激光第一帧沿已公布方向发射，之后才缓慢转动，遇到实心障碍截断；落剑和红雷在发布前检查真实地面，不破坏或点燃方块。普通危险实体在攻击结束、取消、玩家失效、Boss 死亡和重新加载时取消；红雷持续雷区会跨越普通攻击，直到下一次红雷天罚或 Boss/阶段结束时清除。

## P3 防御与出招总则

杨戬处于待机或格挡姿态且防御条有值时，来自四格以外的实体攻击会自动格挡；连续 35 tick 内受到两次以上近战攻击时，待机状态也会提高正面格挡倾向，三个阶段均生效。远处投射物沿原速度反向弹回，并将其发射者改为杨戬；若伤害来源的 `actual` 与 `direct` 是同一生物，则该生物受到 20 tick（1 秒）的强制停滞。普通正面格挡也会触发同样的眩晕和击退。防御条归零时不再格挡，直到延迟回满。

P3 进入后先等待 10 tick，再根据玩家距离、是否使用物品、当前生命比例、上一招和技能冷却进行加权选择；每招结束保留 28 tick 收势窗口，开眼后的前 9 秒不会抽取 `DIVINE_JUDGEMENT`。所有危险实体由服务器发布，最多同时存在 48 个，同一玩家受到落点、激光和雷击的伤害共用 12 tick 间隔。

| 技能 | 时间轴与队列 |
| --- | --- |
| 天眼激光 | 预警 16 tick → 固定光束照射 32 tick。 |
| 横向扫射激光 | 准备 24 tick（不显示预警线）→ 本体第 1 次（32 tick）→ 分身第 1 次（与本体重叠后半程）→ 本体第 2 次 → 分身第 2 次 → 本体第 3 次 → 分身第 3 次；每次切换间隔 16 tick，最后分身完成剩余半程。 |
| 追踪激光 | 预警 22 tick → 50 tick 三维追踪，每 tick 转向受限，持续横移可甩开。 |
| 万剑诀 | 升空 20 tick；第 26、56、86 tick 依次发布三波、每波最多 8 个落点；第 118～138 tick 降落。 |
| 剑雨 | 第 20、40、60、80 tick 依次发布四波，每波最多 8 个落点，单波预警 20 tick。 |
| 红雷天罚 | 第 14、28、42、56 tick 依次发布四轮，每轮 3 个落点，预警 16 tick。 |
| 神威横扫 | 预警 20 tick；近距离随机使用半径 10 格一周横扫，否则使用半径 12 格、170° 扇形，攻击持续 10 tick，链节与命中均按右向左旋转。 |
| 空中连招 | 升空 → 第 24 tick 万剑（6 剑）→ 第 60 tick 追踪激光 → 第 104 tick 锁定俯冲并在 124～130 tick 命中 → 第 140 tick 红雷。 |
| 神威天裁 | 升空 24 tick → 第 50 tick 万剑（9 剑）→ 第 88 tick 俯冲准备并在 110～115 tick 命中 → 第 130 tick 扫射激光 → 第 184 tick 固定激光 → 第 228 tick 红雷 → 第 264 tick 剑雨 → 第 284～304 tick 降落，第 305 tick 收势；冷却 1200 tick。 |

## 模型与配置

保留此前确认的人物造型和贴图。P3 新增 13 套动画，0.9.1 再加入矛、斧、剑、鞭四套垫步，全部阶段共 48 套，46 个原始人物骨骼联动，包括胸腰、肩肘腕、膝踝、发束与裙甲。可编辑工程为 [`modeling/yang_jian_p3.bbmodel`](../modeling/yang_jian_p3.bbmodel)，包含三种 P2 备用兵器，总计 2696 个方块、50 个骨骼组。

服务器 `config/myriad_calamity-common.toml`：

```toml
[yangJian]
health = 640.0
damage = 9.0
guard = 180.0
phase2Guard = 220.0
phase3Guard = 260.0
phase3HealthFloor = 0.4
```

`damage` 等比例调整三个阶段的招式伤害；`phase3HealthFloor` 范围 0～1，设为 0 可关闭第三阶段入场补血。旧配置缺失字段由 NeoForge 补全。新最大生命值在新召唤的 Boss 上生效。

旧版已完成的 P1 / P2 挑战仍可正常返程，重新开启挑战才开始完整三阶段，首通奖励记录不重置。原场地可继续使用，无需重建世界。
