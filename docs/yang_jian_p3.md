# 杨戬 · P3 天眼全开·神威

Minecraft 1.20.1 / Forge 47.4.23（`mc-1.21.1` 分支为 NeoForge 21.1.233），模组版本 0.9.4。

使用登云符进入原云海神台，连续进行 P1 → P2 → P3。生命降至最大值 50% 后取消攻击、清除召唤物，播放 70 tick（3.5 秒）的天眼开启动画，期间免伤。随后换成紫色最终阶段血条，天眼发光，身体周围出现能量效果。

P3 的防御条默认 260 点。杨戬受到伤害时先扣防御条，防御条仍有值就不会损失生命；防御条归零后才会造成生命伤害，归零后的 2400 tick（两分钟）暴露时间结束时重新回满。防御条存在时才会触发远距格挡或连续近战压力格挡，空条期间投射物和近战伤害都直接作用于生命。开眼时保留现有生命；若低于配置的生命保底则补至保底，默认最大生命的 40%（默认最大生命 640，保底 256）。P3 单次生命伤害仍限制为最大生命的 15%，防止巨额伤害跳过战斗。最终死亡播放跪地收势，立即撤销所有危险效果，开放返程和首通奖励。

## 技能与预警

| 技能 | 流程与躲避方式 |
| --- | --- |
| 天眼开启 | 抬手聚气、开眼、展开手臂；只在 P2 破防时触发。 |
| 天眼激光 | 天眼蓄光 10 tick（0.5 秒）后，射出持续 8 tick 的细束高伤激光；蓄光期间头部与射线持续跟随玩家，发射瞬间才按玩家当前位置锁定方向，只显示眼部蓄力，不显示瞄准线。 |
| 横向扫射激光 | 起手准备 24 tick（不显示预警线）；本体与半透明、不可受击的视觉分身交替各扫 3 次。每次扫射 32 tick，半程 16 tick 切换；本体每次切换都会传送到新位置，分身在本体附近生成并在下一轮换位。每段光束与头部都**顺时针**掠过。 |
| 万剑诀 | 升空期间及悬空时不断生成环绕本体的实体飞剑；每 4 tick 生成 3 把，共 23 波、69 把。每把旋转 12～14 tick 后朝释放瞬间的目标位置射出，前段有限追踪，无预警线或落点圈。 |
| 剑雨 | 不再分波：从第 20 tick 起每 4 tick 落下 2 个落点，整段持续约 5.6 秒（到第 150 tick），每个落点各自提前 20 tick 预警。剑尖朝下，实际落地后造成范围伤害。 |
| 红雷天罚 | 连续四轮、每轮三个红色落点；提前 16 tick 预警，随后动态分叉红雷落下。雷柱在落下瞬间与落地之后都保持 14 格全高；落点会留下不断变化的地面与低空电弧，在范围内按伤害间隔反复造成伤害，直到下一次红雷天罚开始时清除上一轮雷区。 |
| 神威横扫 | 三尖两刃刀蓄力 20 tick，释放半径 12 格、170° 扇形；近距离也可能改为半径 10 格的一周横扫。横扫期间长枪本身纵向伸长到 3 倍（枪尖接近 12 格判定半径）并保持到收招，取代原来的红色闪电，落地范围由兵器痕迹表示。 |
| 空中连招 | 升空 → 飞剑 → 细束天眼激光 → 锁定俯冲与刀击 → 红雷 → 收势。落剑、俯冲和雷击保留预警；激光只保留天眼蓄光。 |
| 神威天裁 | `DIVINE_JUDGEMENT`：升空聚气 → 密集剑雨 → 俯冲刀击 → 两段激光 → 红雷 → 再一轮密集剑雨 → 落地。两处剑雨都改成与空中连招相同的三轮密集连发（每轮 8 把、逐轮缩短预警），不再使用原来的连续落点；起手明显提示，冷却 60 秒；各段之间留出移动窗口。 |

最终阶段各招都保留短收招时间，普通技能结束后停顿 28 tick；技能按距离、玩家使用物品、剩余生命和冷却加权选择，避免原地重复同一招。开眼后最初 9 秒不抽取终极技能。技能池只保留细长的天眼激光；那根又粗又不横扫、只以每 tick 0.7° 缓慢跟人的持续光柱（追踪激光）已从 P3 技能池移除。

三个阶段均用快速垫步替代普通走路追近。每段 10 tick：第 0 tick 起立即前移，中间持续至第 8 tick，末尾 2 tick 收步，最多前移 6 格。P1/P2 接近到约 3.2 格，P3 保留约 8.5 格远程作战距离。起步与移动途中检查地面，障碍会阻挡移动；玩家迎面靠近时提前收步。从 0.9.3 起，垫步第 0 tick 同步从副手直接投出一枚无预警直线飞刀，默认 7 点伤害，可横移躲避。前移本身没有接触伤害，飞刀独立判定命中。攻击状态使用独立的生物锁定 UUID；外部系统把仇恨切换为其他存活生物后，杨戬会继续用该生物作为当前阶段目标，近战、飞刀、飞剑、激光和落点伤害都能命中它。

所有激光统一为连续的黄白内芯、分层金色光晕、三股动态电弧及末端闪光。蓄力只发生在眼睛，不绘制路线；常规技能池中的两招纯激光（天眼激光、横向扫射激光）在整段蓄力期间都会点亮天眼，即使本体光束实体在分身轮换间隙短暂缺席也保持发光。头部使用完整骨骼与镜像变换逆算朝向，逐帧对齐实际射线；本体与分身各自跟随自己的光束，起点附着额头，平滑后的射线重新检查障碍。P3 待机、垫步及空中施法更及时转向目标；已锁定的横扫保留施法时的身体方向，让头部跟随固定扫射弧，避免目标移动把攻击轨迹一起转偏。

杨戬处于待机或格挡姿态时，来自四格以外的实体攻击会自动格挡。远处投射物沿原速度反向弹回，并将其发射者改为杨戬；若伤害来源的 `actual` 与 `direct` 是同一个生物，则该生物受到 20 tick（1 秒）的强制停滞。普通正面格挡也会触发同样的眩晕和击退。杨戬自有的三尖两刃刀、飞剑及机枢剑光保留原控制者，避免反弹时破坏技能生命周期。

剑雨及组合技能中的落剑先生成分离的落点布局，再发布预警，避免场边裁剪把多个圆圈压到同一个位置。移动预测最多提前 4.5 格。激光、落剑与红雷危险实体上限为 48，同一目标共用 12 tick 的伤害间隔。万剑诀使用独立的飞剑队列，同时最多保留 48 把，命中或飞行到期移除，未射出的剑在招式中断时取消。

范围预警由 `showAttackIndicators` 决定：默认 `false` 时不再绘制任何地面预警，三阶段落点只用落地后的剑痕与雷痕表示实际范围（落剑本体仍会下坠提示）；`true` 时恢复原来的实际几何预警图形，预警和命中读取同一个服务器计划。激光与飞剑没有预警线；激光沿其服务器方向发射，遇到实心障碍截断。落剑和红雷在发布前检查真实地面，不破坏或点燃方块。普通危险实体在攻击结束、取消、目标失效、Boss 死亡和重新加载时取消；红雷持续雷区会跨越普通攻击，直到下一次红雷天罚或 Boss/阶段结束时清除。

## P3 防御与出招总则

杨戬处于待机或格挡姿态且防御条有值时，来自四格以外的实体攻击会自动格挡；连续 35 tick 内受到两次以上近战攻击时，待机状态也会提高正面格挡倾向，三个阶段均生效。远处投射物沿原速度反向弹回，并将其发射者改为杨戬；若伤害来源的 `actual` 与 `direct` 是同一生物，则该生物受到 20 tick（1 秒）的强制停滞。普通正面格挡也会触发同样的眩晕和击退。防御条归零时不再格挡，直到延迟回满。

P3 进入后先等待 10 tick，再根据玩家距离、是否使用物品、当前生命比例、上一招和技能冷却进行加权选择；每招结束保留 28 tick 收势窗口，开眼后的前 9 秒不会抽取 `DIVINE_JUDGEMENT`。所有危险实体由服务器发布，最多同时存在 48 个，同一玩家受到落点、激光和雷击的伤害共用 12 tick 间隔。

| 技能 | 时间轴与队列 |
| --- | --- |
| 天眼激光 | 眼睛蓄光 10 tick（全程跟随玩家）→ 细束照射 8 tick，方向在发射瞬间锁定；无路线预警。 |
| 横向扫射激光 | 准备 24 tick（不显示预警线）→ 本体第 1 次（32 tick）→ 分身第 1 次（与本体重叠后半程）→ 本体第 2 次 → 分身第 2 次 → 本体第 3 次 → 分身第 3 次；每次切换间隔 16 tick，最后分身完成剩余半程。 |
| 万剑诀 | 升空 20 tick；第 18～106 tick 每 4 tick 生成 3 把旋转飞剑，旋转 12～14 tick 后射出；第 118～138 tick 降落。 |
| 剑雨 | 第 20 tick 起每 4 tick 连发 2 个落点，直到第 150 tick（共 33 次投放、66 把剑），单点预警 20 tick；动画仍是 8 个左右交替举手的施法节拍。 |
| 红雷天罚 | 第 14、28、42、56 tick 依次发布四轮，每轮 3 个落点，预警 16 tick；雷柱保持 14 格全高。 |
| 神威横扫 | 预警 20 tick；近距离随机使用半径 10 格一周横扫，否则使用半径 12 格、170° 扇形，攻击持续 10 tick，链节与命中均**顺时针**转；长枪纵向伸长至 3 倍并保持到收招。 |
| 空中连招 | 升空 → 第 24／30／36 tick 连续三轮密集剑雨（每轮 8 把，预警依次 18／14／10 tick）→ 第 60 tick 细束天眼激光（蓄光 16 tick、照射 22 tick，蓄力全程跟随玩家、发射瞬间锁定）→ 第 104 tick 锁定俯冲并在 124～130 tick 命中 → 第 140 tick 红雷。 |
| 神威天裁 | 升空 24 tick → 第 50／56／62 tick 连发三轮剑雨（每轮 8 把，预警 26／22／18 tick，第 76／78／80 tick 落地）→ 第 88 tick 俯冲准备并在 110～115 tick 命中 → 第 130 tick 蓄光 24 tick 后快速横扫 16 tick（原为 32 tick）→ 第 184 tick 蓄光 10 tick 后释放 8 tick 的天眼细束 → 第 228 tick 红雷 → 第 264／270／276 tick 再连发三轮剑雨（每轮 8 把，预警 24／20／16 tick，第 288／290／292 tick 落地）→ 第 284～304 tick 降落，第 305 tick 收势；冷却 1200 tick。 |

## 模型与配置

保留此前确认的人物造型和贴图。P3 新增 13 套动画，0.9.1 再加入矛、斧、剑、鞭四套垫步，全部阶段共 48 套，46 个原始人物骨骼联动，包括胸腰、肩肘腕、膝踝、发束与裙甲。可编辑工程为 [`modeling/yang_jian_p3.bbmodel`](../modeling/yang_jian_p3.bbmodel)，包含三种 P2 备用兵器，总计 2696 个方块、50 个骨骼组。

服务器 `config/myriad_calamity-common.toml`：

```toml
[yangJian]
health = 640.0
damage = 9.0
guard = 180.0
phase2Guard = 220.0
phase3Guard = 260.0
phase3HealthFloor = 0.4
```

`damage` 等比例调整三个阶段的招式伤害；`phase3HealthFloor` 范围 0～1，设为 0 可关闭第三阶段入场补血。旧配置缺失字段由 Forge 补全。新最大生命值在新召唤的 Boss 上生效。

旧版已完成的 P1 / P2 挑战仍可正常返程，重新开启挑战才开始完整三阶段，首通奖励记录不重置。原场地可继续使用，无需重建世界。
